# Deal Closer - The BD Pitch Game

A business-development pitch game in a single HTML file. Read each company's situation (modeled on real earnings-report patterns), then pick the hook, the ask, and the right person. 5 deals, scored out of 45.

Play: open `index.html` in any browser. No build, no dependencies.

The method it teaches: read what the company actually said, find the person whose problem it is, ask for 15 minutes.
